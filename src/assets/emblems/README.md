# ตราครุฑ

| ไฟล์ | คืออะไร |
|---|---|
| `garuda-source.jpg` | ภาพสแกนต้นทาง 648×720 ขาวดำ คัดลอกมาจาก repo เว็บหลัก (`Lawslane/src/pic/National Emblem of Thailand.jpg`) |
| `garuda.pdf` | ไฟล์ที่ renderer ใช้จริง สร้างจากภาพต้นทางด้วย `scripts/legal-doc/make-garuda.py` |

```bash
python3 scripts/legal-doc/make-garuda.py src/assets/emblems/garuda-source.jpg src/assets/emblems/garuda.pdf
```

สคริปต์ตัดขอบว่าง แปลงเป็นภาพ 1-bit แล้วฝังเป็น stencil mask (`/ImageMask`)
ระบายสีดำ พื้นจึงโปร่งใส วางทับเส้นหรือกรอบได้ และไฟล์เหลือราว 17 KB
renderer เรียกผ่าน `page.embedPdf()` ครั้งเดียวต่อเอกสาร

**ยังไม่ใช่ vector** ที่ขนาดหัวกระดาษราชการ (ราว 3 ซม.) ความละเอียดเกิน 500 dpi
พอสำหรับพิมพ์ แต่ถ้าขยายใหญ่มากจะเห็นขอบหยักจากการสแกน ถ้าได้ไฟล์ vector มา
ให้วาง PDF หน้าเดียวทับ `garuda.pdf` ได้เลยโดยไม่ต้องแก้โค้ด
(ถ้าต้นทางเป็น SVG ให้เก็บเป็น `garuda.svg` คู่กันแทน `garuda-source.jpg`)

## ข้อกำกับการใช้

เอกสารที่ระบบสร้างไม่ใช่เอกสารของทางราชการ การวางตราครุฑลงไปทำให้มันหน้าตา
เหมือนแบบพิมพ์ราชการจริง ซึ่งมีกฎหมายและระเบียบกำกับการใช้ตราแผ่นดินอยู่
จึงใช้เฉพาะเป็นเอกสารประกอบการเรียนเท่านั้น

ด้วยเหตุนี้ `src/lib/legal-doc/ir.ts` → `assertNoticePolicy()` **บังคับ** ให้
เอกสารชนิด `blank-form` ที่มีตราครุฑต้องมีข้อความกำกับท้ายหน้าเสมอ ปิดไม่ได้
ถ้าจะเปลี่ยนนโยบายนี้ ให้แก้ที่ฟังก์ชันนั้นจุดเดียว

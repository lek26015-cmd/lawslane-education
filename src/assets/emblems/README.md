# ตราครุฑ (ไฟล์ตัวแทน — ยังไม่ใช่ของจริง)

`garuda.pdf` ในโฟลเดอร์นี้ตอนนี้เป็น **ไฟล์ตัวแทน** รูปวงกลมกับสี่เหลี่ยมกากบาท
จงใจให้ดูออกทันทีว่าไม่ใช่ครุฑ เพื่อพิสูจน์ว่าเส้นทางการวาด emblem ทำงาน
โดยไม่ต้องตัดสินใจเรื่องลิขสิทธิ์และความเหมาะสมแทนเจ้าของโปรเจกต์

## จะใส่ของจริงต้องทำอะไร

วางไฟล์ PDF หน้าเดียวที่เป็น vector ล้วนทับที่ `garuda.pdf` — renderer เรียกผ่าน
`page.embedPdf()` ครั้งเดียวต่อเอกสาร จึงคมทุกขนาดและไฟล์ไม่โต
ถ้าต้นทางเป็น SVG ให้เก็บไว้เป็น `garuda.svg` คู่กันเพื่อให้แก้ต่อได้

## สองเรื่องที่ต้องตัดสินใจก่อน ไม่ใช่เรื่องเทคนิค

1. **ที่มาและสิทธิ์** — ตราครุฑเป็นงานของทางราชการไทย โดยทั่วไปถือว่าไม่มีลิขสิทธิ์
   ตามมาตรา ๗ แห่ง พ.ร.บ. ลิขสิทธิ์ แต่ **repo นี้เป็น public** ควรบันทึกไว้ตรงนี้ว่า
   เอาไฟล์มาจากไหนและอ้างสิทธิ์อะไร ก่อน commit

2. **ความเหมาะสมในการใช้** — เอกสารที่ระบบสร้างไม่ใช่เอกสารของทางราชการ
   การวางตราครุฑลงไปทำให้มันหน้าตาเหมือนแบบพิมพ์ราชการจริง ซึ่งมีกฎหมายและ
   ระเบียบกำกับการใช้ตราแผ่นดินอยู่

   ด้วยเหตุนี้ `src/lib/legal-doc/ir.ts` → `assertNoticePolicy()` **บังคับ** ให้
   เอกสารชนิด `blank-form` ที่มีตราครุฑต้องมีข้อความกำกับท้ายหน้าเสมอ ปิดไม่ได้
   ถ้าจะเปลี่ยนนโยบายนี้ ให้แก้ที่ฟังก์ชันนั้นจุดเดียว
